How to Use

Welcome to Pro README Generator! Creating an amazing GitHub profile is easy:

  1. Fill out the sections in the left panel. None of the fields are strictly mandatory, but Name is recommended.
  2. Select the technologies and tools you are familiar with from the Skills section.
  3. If you check the GitHub Stats options, make sure you have entered your GitHub username in the Social Links section, otherwise the cards won't load.
  4. Watch the live preview update on the right side as you type!
  5. Once you are happy with the result, click Copy Code or Download .md.
  6. Go to your GitHub profile, create a new repository with the same name as your username, and paste the code into its README.md file!
